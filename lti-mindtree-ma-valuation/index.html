Was the LTI–Mindtree merger priced fairly?

L&T Group merged two of its own IT-services companies at a 73:100 stock-for-stock exchange ratio. This model tests that ratio nine independent ways — DCF, trading comps, precedent transactions, a synergy backsolve, event study, and more — from a single 49-sheet, fully-linked, zero-formula-error workbook.

01

The approach

Both companies get an independent full three-statement forecast (FY2023E–FY2032E), a bottom-up WACC built from Damodaran sector beta relevered to each company's actual capital structure, and a value-driver DCF — all built from real filed financials, all live Excel formulas, never pasted values. Both models sit in the same workbook, so every cross-company link (exchange ratio, comps, precedent transactions) stays a live same-file reference rather than a fragile cross-file one.

The pattern across all nine cross-checks is consistent: this reads as a merger of two already-affiliated companies priced at relative value, not a competitive third-party buyout that would demand a control premium.

A real bug, caught and fixed

A methodology audit found the Cost of Debt formula was silently dropping the Sovereign Default Spread term (it should be Risk-Free Rate + Sovereign Spread + Company Spread; it was only Risk-Free Rate + Company Spread). Fixed across all three linked files. Impact was small given both companies are ~99% equity-funded — WACC moved roughly +1.3 basis points, value/share moved about −0.17% each — but it was a genuine correctness fix, verified before it stood uncorrected.

Built to be checked

  • ✓Balance Check ties to exactly 0 across all 10 forecast years, for both companies.
  • ✓Best Owner Analysis initially used 5 self-derived levers instead of the actual Copeland-Koller framework — caught via source re-verification and rebuilt with the correct levers.
  • ✓A Value of Control test initially forced Mindtree's margin down to the industry median even though it already outperforms it, violating the framework's own governing rule — caught, corrected, and documented on the sheet.
  • ✓A units-mismatch bug (an absolute-Rupee column mislabeled as "Rs. Millions") was caught before the LBO Floor's per-share output was trusted, by checking the result landed in a sane range.
  • ✓Mindtree's event-study regression was rebuilt from a simplified beta=1 fallback to full market-model rigor, after sourcing 119 additional days of delisted-ticker price history.
  • ✓A workbook-navigation bug (hyperlinks silently detached from their labels after row insertions) was caught by testing actual link-to-target alignment, not just that the destination sheet existed.
